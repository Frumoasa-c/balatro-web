# Balatro Web Demo

独立的浏览器版规则原型，参考 `../balatro-gba` 中的手牌判定、回合资源与小丑事件组织方式实现。

## 运行

直接用浏览器打开 `index.html`。不需要 Node.js、Python 或构建步骤。

## 当前实现

- 52 张标准牌组、洗牌、抽牌、弃牌与回收弃牌堆
- 最多选择 5 张牌，支持高牌至同花顺的判定
- 基础筹码、牌面筹码、倍率与最终得分结算
- 小盲注 / 大盲注 / Boss 三阶段及底注递进
- 商店、利息、重掷，以及 10 种基础小丑
- 浏览器本地存档与重新开始

这是非商业的粉丝规则原型；Balatro 的名称、视觉语言和原始游戏概念归其权利方所有。
